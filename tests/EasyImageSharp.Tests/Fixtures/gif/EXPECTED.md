# GIF fixtures

Generated by `gen_gif()` in `../generate.py` (Python 3.11, Pillow 11.3). All images are built as
palette ("P") images with an explicit palette so the encoder cannot alter any color; Pillow may
re-order or trim palette entries, so tests compare decoded *colors*, never palette indices.
Pillow always writes an LZW minimum code size of 8; smaller code sizes are covered by the hand-crafted
files in `GifTests.cs`.

Every animated frame below describes the **fully composited canvas** the decoder must produce for that
frame index (`image.Frames[i]`), which is what a viewer displays.

| File | Screen | Version | GCT depth | Frames | Notes |
|---|---|---|---|---|---|
| `static_rgb.gif` | 64x48 | 87a | 6 (64 colors) | 1 | non-interlaced, no extensions |
| `static_interlaced.gif` | 64x48 | 87a | 6 | 1 | same pixels as `static_rgb.gif`, interlace flag set |
| `transparent.gif` | 40x30 | 89a | 2 | 1 | GCE with transparent index, comment extension |
| `animated_3frames.gif` | 32x32 | 89a | 2 | 3 | full-size frames, disposal 2, delay 100 ms, NETSCAPE loop, local color tables on frames 2-3 |
| `animated_disposal_none.gif` | 48x32 | 89a | 2 | 3 | disposal 1; frames 2-3 are 16x16 sub-rectangles at (16,8) and (32,16) with local tables and a transparent index for unchanged pixels |
| `local_palette.gif` | 24x16 | 89a | 2 | 2 | frame 2 uses a local color table (2 used colors + transparent index) whose colors are not in the global table |

## Pixel values

**static_rgb.gif / static_interlaced.gif** — palette entry `i` (0..63) = `(4i, 255-4i, (37i) mod 256)`;
pixel `(x, y)` uses entry `(x + y) mod 64`. Both files decode to identical pixels.

**transparent.gif** — left half (`x < 20`) red `(255,0,0)`, right half green `(0,255,0)`; the rectangle
`x in [10,30), y in [8,22)` is transparent (canvas stays `(0,0,0,0)`; `Rgb24` targets see `(0,0,0)`).

**animated_3frames.gif** (disposal 2 → each frame is only its own content)

- frame 0: red `(255,0,0)` with a blue `(0,0,255)` 8x8 square at `(4,4)`
- frame 1: green `(0,255,0)` with a white `(255,255,255)` 8x8 square at `(12,12)`
- frame 2: blue `(0,0,255)` with a yellow `(255,255,0)` 8x8 square at `(20,20)`

**animated_disposal_none.gif** (disposal 1 → later frames keep earlier content)

- frame 0: gray `(128,128,128)` with a red 16x16 rectangle at `(0,0)`
- frame 1: frame 0 plus a green rectangle `x in [16,32), y in [8,24)`
- frame 2: frame 1 plus a blue rectangle `x in [32,48), y in [16,32)`

**local_palette.gif**

- frame 0: `x < 12` → `(10,20,30)`, else `(200,100,50)`
- frame 1: `x < 12` → `(0,128,255)`, else `(255,0,128)`

`Identify` must report the screen size, frame count and GCT depth (bits per pixel) from the table above.
