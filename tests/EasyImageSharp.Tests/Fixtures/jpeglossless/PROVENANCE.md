# Lossless JPEG fixtures: provenance

Every file here is written by `generate.py` in this folder (Python 3.11+, `numpy>=2`, `imagecodecs>=2024.1`).
None of it comes from EasyImageSharp. `manifest.json` lists each file with its precision, predictor, point
transform, restart interval, colour type and the decoders that confirmed it.

| Files | Encoder | Ground truth |
| --- | --- | --- |
| `gray16_p1`-`p7`, `gray2_p4`, `gray7_p5`, `gray8_p1`, `gray12_p6`, `rgb8_p7`, `rgb12_p3`, `rgb16_p4` | libjpeg-turbo 3.1.3 (`imagecodecs.jpeg8_encode(lossless=True)`) | the source samples; libjpeg-turbo's decode was checked to reproduce them exactly |
| `ycc8_p1` | libjpeg-turbo 3.1.3, YCbCr components | libjpeg-turbo's decode to RGB (the colour transform is not lossless) |
| `gray12_pt1_p1`, `gray12_pt3_p6` | the T.81 Annex H encoder in `generate.py` | source samples with the point transform applied; confirmed by libjpeg-turbo and by jpegsof3 |
| `gray12_restart_p5`, `rgb10_restart_pt2_p7`, `rgb8_planar_p2`, `cmyk12_p4` | the T.81 Annex H encoder in `generate.py` | source samples (point transform applied); confirmed by libjpeg-turbo's decoder |
| `rgb8_sub22_p1` | the T.81 Annex H encoder in `generate.py`, first component sampled 2x2 | libjpeg-turbo's decode (it upsamples lossless frames by replication) |

`<name>.u16.gz` holds the ground truth: gzip-compressed little-endian `uint16` samples, row-major, channels
interleaved, in the file's own precision.

## Source image

- `gray16_*` and the `gray12_*` files of the spec-derived encoder use a crop of libjpeg-turbo's `monkey16.pgm`,
  which `generate.py` downloads from
  <https://raw.githubusercontent.com/libjpeg-turbo/libjpeg-turbo/0103036f949f30c4f794e2032a03eb183b007092/testimages/monkey16.pgm>
  and checks against SHA-256 `8d122b926fba68154c4e3d73d29496c8bc67a8498ab34bb3edde56093364359f`. Only the encoded
  crops are committed.
- Licence: Modified (3-clause) BSD License, per libjpeg-turbo's `testimages/LICENSE.txt` at that commit (the full
  licence text is reproduced in `../jpeg12/PROVENANCE.md`).
- Every other source is a fixed-seed synthetic pattern generated by `generate.py`.

## Tools

- imagecodecs 2026.3.6 (BSD-3-Clause), bundling libjpeg-turbo 3.1.3 (IJG, BSD-3-Clause and zlib licences) and
  jpegsof3 (the lossless decoder from dcm2niix).
- jpegsof3 cannot decode restart intervals or multi-component scans and returns samples before the point transform
  is undone; the generator accounts for both and only uses it where it applies.
